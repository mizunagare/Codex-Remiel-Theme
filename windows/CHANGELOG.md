# Windows Changelog

## 1.0.0 — 2026-07-23

### 新增

- 基于自包含 v2 主题包重建“蕾米埃尔｜星芒圣翼”。
- 侧栏、项目、任务、插件、权限、听写与发送按钮使用粉紫星芒/机械圣翼图标。
- 首页使用连续 16:9 背景，任务页使用低干扰环境模式。
- `appearance: auto` 同时兼容 Codex 浅色与深色外观。

### 性能

- 不捆绑主题宠物，不改变用户已有宠物。
- 加载与处理状态只使用 transform/opacity 动画，避免逐帧滤镜和大面积实时模糊。
- 延续按脏区调度的侧栏、输入区和 spinner 更新，不在每次 DOM 变化时全量重绘。
